## 実装履歴
### 1. Image Lightbox の修正 (2026-09-28)
- **概要**: サイトの画像の上に「チェックボックス」が表示される問題を解決。
- **原因**: 本番環境において、画像を拡大表示する機能（lightbox）を提供するため、すべての画像が自動的に `<label class="checkbox-label"><input type="checkbox">...` のHTML構造にラップされていました。しかし、これに対するCSSがリポジトリ内に存在しなかったため、チェックボックスが意図せず表示されていました。
- **対応**: `src/custom.css` に対して、チェックボックスを隠し（`display: none !important`）、lightbox用の表示制御を行うスタイルを記述して対応しました。画像ファイルの修正ではないことがポイントです。
